## 到室外按这个顺序测

1. 人工控制机器狗到开阔处，打开“采集”。三个输入都要新鲜，且定位有效。质量码 `4=固定解`、`5=浮点解`、`2=差分解`；第一次验证楼梯边界建议等固定解。只有 `1` 时先别正式采集。
2. 看步态是否显示平地/楼梯和真实码值。手动平地 `0x1001`、手动楼梯 `0x1003`；导航模式相应为 `0x3002/0x3003`。如果一直是 `0x0/未知`，先核对底盘反馈，不能当作步态记录正常。网页不会替你切换步态。
3. 点“新建地图采集”，由你遥控走一段短路。先测平地，再在合适条件下人工切步态。检查轨迹增长、定位质量和步态变化。如不想继续，点“取消录制（保留原始数据）”；它与“结束并建图”不同。可试暂停/继续，但暂停会形成不连通的轨迹缺口；路线规划不会自动跨过去。
4. 点“结束”，进入“合并”并生成预览。逐项选择“连接/保持分开”，重叠路段选择保留哪次步态。靠近或交叉不自动连通。确认后保存新 ID，例如 `outdoor-field-v1`，再点“加载”。
5. 从已加载地图点“补采”，人工走一条短支路；结束、确认连接、保存为 `outdoor-field-v2` 并加载。旧版仍保留。
6. 在“规划”手选起点、道路上的终点，分别测正向和反向。检查路线经过正确路口，楼梯及低精度区段正确。加一个地点，重载地图后确认仍在。最后停止采集，再收机。

若结束后提示没有可用定位或连续移动路线，原始消息仍在，但没有可保存的路网。不要把红色错误提示当作已建图成功。

录制页面约每秒更新：有效位置显示蓝色圆点，采集轨迹显示青绿色虚线（预览最近 2000 个有效点，完整记录仍保存在山猫）。轨迹超出视野可点右上角“显示全图”。录制中路线暂不按步态着色，右侧显示当前步态和反馈新鲜度；结束时自动滤波建图，保存并加载后按平地/楼梯显示区段。滤波保留步态边界，不能修复 GNSS 的整体位置偏差。
